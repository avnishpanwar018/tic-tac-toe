# 🎮 Tic-Tac-Toe

A modern, high-fidelity Tic-Tac-Toe game built with a futuristic tech aesthetic. Play locally with a friend or challenge the AI, complete with neon visual transitions and real-time audio synthesis.

![Technologies](https://img.shields.io/badge/tech-HTML5%20%7C%20CSS3%20%7C%20VanillaJS-orange)

---

## ✨ Features

-   **Dual Game Modes**: Toggle seamlessly between local **2 Players (PvP)** mode and **vs AI** mode.
-   **Neon Aesthetic**: Built with a sleek dark theme (`#0f0f1a`), vibrant cyan/pink color schemes, pulsing win glows, and micro-animations.
-   **Programmatic Audio**: Real-time sound synthesis using the browser's native **Web Audio API**—no external audio files required!
-   **Session Scoreboards**: Real-time win/draw counters.
-   **Responsive Design**: Optimized for desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

-   **HTML5**: Structured semantic document markup.
-   **CSS3**: Custom variables (CSS custom properties), CSS Grid, Flexbox, keyframes, and neon glow effects.
-   **JavaScript (ES6+)**: Pure, vanilla DOM event handling, game loop, AI move generation, and audio synthesizer.

---

## 🚀 Getting Started

Since this is a client-side static web application, no installation or compilation is needed.

1.  Clone the repository:
    ```bash
    git clone https://github.com/avnishpanwar018/tic-tac-toe.git
    ```
2.  Open the game in your browser:
    ```bash
    # Windows
    start index.html

    # macOS
    open index.html

    # Linux
    xdg-open index.html
    ```
